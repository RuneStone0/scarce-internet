Method and caveats

  • Every number is stated by a public API and regenerated from scratch each run — nothing is hand-entered or interpolated. A source that fails is recorded as degraded and its value carried forward from the previous run rather than silently becoming blank.
  • Months with no Lightning reading are left blank. An interpolated point would look like data without being data.
  • Lane membership is editorial. We pick four flagship repos per rail and count commits per repo-month. Change the membership and the ratios move — that is a real limitation, which is why the raw per-repo data is published alongside.
  • Historical stars are not available. The stargazers endpoint returns 404 for our token, so a star series starts from the first collection and grows forward; commit and release history is used for the back history instead.
  • Only a trend is claimed. No causal claim, no forecast, no position.
